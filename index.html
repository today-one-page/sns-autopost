소개

이 도구는 오늘도 한 페이지가 만든 글귀 카드와 일상 영상을 운영자 본인의 틱톡 계정 초안함으로 보내는 데스크톱 프로그램입니다. 운영자가 미리보기로 내용을 확인한 뒤 직접 보내기를 눌러야 전송되며, 최종 게시는 운영자가 틱톡 앱에서 직접 마무리합니다.

  1. 운영자가 틱톡 로그인(TikTok Login Kit)으로 본인 계정을 연결합니다.
  2. 보낼 영상·사진과 캡션을 미리보기로 확인합니다.
  3. 보내기를 누르면 틱톡 Content Posting API로 초안함에 업로드됩니다.
  4. 틱톡 앱 알림함에서 내용을 편집하고 게시합니다.

About (English)

This is a desktop tool used by Today One Page (오늘도 한 페이지) to send its own quote cards and everyday videos to the operator's own TikTok account inbox as drafts. Nothing is sent until the operator reviews a preview and clicks send, and the operator completes every post manually in the TikTok app. The tool uses TikTok Login Kit and the Content Posting API (video.upload).
